# Тренировки: mini app в Telegram для набора массы 69 → 80 кг за 9 месяцев

Telegram Mini App, который ведёт программу целиком: тренировка на сегодня,
запись подходов с автоматической прогрессией весов, утренние взвешивания,
график факт/план, калории и БЖУ по фазам, добавки, дни тренировок для
напоминаний. Бот в чате почти не нужен — он только открывает приложение и
присылает напоминания.

Технически это один сервис: **FastAPI** отдаёт собранный **React**-фронтенд
и REST API, а телеграм-бот работает через вебхук внутри того же процесса.
Данные — SQLite-файл.

## Структура проекта

```
files/
  core.py           # вся логика и работа с БД (общая для бота и API)
  program.py         # упражнения, подходы, повторы, калории по фазам — правь тут
  auth.py            # проверка подписи Telegram initData
  telegram_bot.py     # бот: /start, напоминания, кнопка меню
  api.py             # FastAPI: REST для мини-аппа + приём вебхука + отдача фронтенда
  requirements.txt
  render.yaml         # блюпринт для платного деплоя на Render
  DEPLOY_FREE_GCP.md   # пошаговая инструкция: бесплатный деплой (Google Cloud + Cloudflare Tunnel)
  DEPLOY_FREE.md       # то же самое, но на Oracle Cloud
  deploy/             # общие скрипты и systemd-юнит для обоих бесплатных вариантов
  frontend/          # React + Vite исходники мини-аппа
    src/
```

## 1. Создать бота (2 минуты)

1. В Telegram открой **@BotFather** → `/newbot`
2. Придумай имя и username (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `1234567890:AAH...` — скопируй его, никому не показывай

Токен я не ввожу и не храню — это делаешь только ты.

Больше от BotFather ничего не нужно: кнопку меню, открывающую приложение,
бот регистрирует сам при каждом запуске (`set_chat_menu_button` в
[telegram_bot.py](telegram_bot.py)).

## 2. Установить зависимости

Нужен Python 3.11+ и Node.js 18+.

```bash
pip install -r requirements.txt
cd frontend && npm install && cd ..
```

## 3. Локальный запуск и тест (через ngrok)

Mini App обязательно открывается по HTTPS, поэтому локально нужен туннель.

```bash
# 1. собрать фронтенд
cd frontend && npm run build && cd ..

# 2. поднять туннель в отдельном терминале (нужен аккаунт на ngrok.com, бесплатно)
ngrok http 8000
# скопируй адрес вида https://xxxx.ngrok-free.app

# 3. запустить сервис
BOT_TOKEN=1234567890:AAH... PUBLIC_URL=https://xxxx.ngrok-free.app uvicorn api:app --port 8000
```

При старте сервис сам:
- поднимет вебхук на `PUBLIC_URL/telegram/webhook/<секрет>`,
- поставит кнопку меню чата, открывающую `PUBLIC_URL`.

Открой бота в Telegram → `/start` → кнопка **🏋 Открыть приложение** (или
значок рядом со скрепкой в поле ввода).

**Разработка фронтенда с горячей перезагрузкой:** вместо `npm run build`
можно держать `npm run dev` (Vite, порт 5173) в отдельном терминале, а
`uvicorn` запускать с `DEV_MODE=1` — тогда открывай `http://localhost:5173`
в обычном браузере, авторизация подменяется тестовым пользователем без
Telegram. Для проверки внутри самого Telegram нужен именно собранный билд
(`npm run build`) — Vite dev server снаружи ngrok не туннелируется без
дополнительной настройки.

## 4. Деплой, чтобы работало 24/7 без твоего компьютера

Три варианта — два бесплатных навсегда (ручная настройка один раз) и один
платный (проще, но $7/мес).

### Бесплатно навсегда: Google Cloud Free Tier + Cloudflare Tunnel

Полная пошаговая инструкция — **[DEPLOY_FREE_GCP.md](DEPLOY_FREE_GCP.md)**.
Рекомендую начать с него: регистрация у Google обычно проходит без
сюрпризов, SSH — прямо в браузере из консоли, ничего скачивать не нужно.

### Бесплатно навсегда: Oracle Cloud Always Free + Cloudflare Tunnel

Тот же принцип, но у Oracle — регистрация капризнее (иногда не с первого
раза), зато лимиты чуть щедрее. Полная инструкция —
**[DEPLOY_FREE.md](DEPLOY_FREE.md)**.

Оба варианта используют одни и те же скрипты из `deploy/` — VM с
настоящим постоянным диском под SQLite, наружу торчит бесплатный
Cloudflare Tunnel — открывать порты не нужно. Требует раз ~30–40 минут
ручной настройки (SSH, systemd), дальше обновления одной командой
(`deploy/update.sh`) после `git push`.

### Проще, но платно: Render

Есть готовый блюпринт (`render.yaml`) — Render подхватывает пуши в GitHub
и деплоит сам. Подойдёт и Railway/Fly.io по тому же принципу
(build: `pip install -r requirements.txt && cd frontend && npm install && npm run build`,
start: `uvicorn api:app --host 0.0.0.0 --port $PORT`).

**Важно про диск:** SQLite-файл должен лежать на *постоянном* диске, иначе
весь прогресс слетает при каждом деплое. На Render это платный план
(Starter, ~7$/мес) с Persistent Disk — он уже прописан в `render.yaml`. На
бесплатных тарифах большинства хостингов диск эфемерный, а сам бесплатный
веб-сервис ещё и засыпает после простоя.

Шаги для Render:

1. Залей содержимое папки `files/` в новый репозиторий на GitHub (именно
   содержимое — `render.yaml` должен быть в корне репозитория):
   ```bash
   cd "files"
   git init
   git add .
   git commit -m "Massbot mini app"
   gh repo create massbot-miniapp --private --source=. --push
   ```
2. На [render.com](https://render.com) → **New** → **Blueprint** → выбери
   этот репозиторий. Render найдёт `render.yaml` и предложит переменные
   `BOT_TOKEN` и `PUBLIC_URL` — `BOT_TOKEN` впиши сразу, `PUBLIC_URL` пока
   оставь пустым.
3. Дождись первого деплоя, скопируй выданный адрес вида
   `https://massbot-miniapp.onrender.com`.
4. В настройках сервиса (**Environment**) впиши `PUBLIC_URL` =
   этот адрес и сохрани — Render передеплоит сервис, при старте он
   зарегистрирует вебхук и кнопку меню уже на реальном адресе.
5. Открой бота в Telegram → `/start`.

С этого момента бот и мини-апп работают сами по себе, без твоего
компьютера. Дальнейшие изменения — просто `git push`, Render передеплоит
автоматически.

## 5. Как пользоваться

Всё — внутри мини-аппа, вкладки внизу:

| Вкладка | Что там |
|---|---|
| 🏋 Сегодня | тренировка на сегодня с рабочими весами, кнопка «Записать тренировку» (сам пересчитает прогрессию), форма для утреннего веса |
| 📊 Статистика | тренд веса, план/факт, график, подсказка по калориям |
| 📋 План | вся раскладка на 9 месяцев по фазам |
| 🍽 Питание | калории и БЖУ текущей фазы, рецепт шейка, сдвиг калорий, добавки с отметкой креатина и серией дней без пропусков |
| ⚙️ Настройки | сводка по программе, дни тренировок для вечерних напоминаний |

**Напоминания от бота:** 8:30 — взвеситься (не приходит, если вес уже
записан), 18:00 — тренировка (только в выбранные дни и если тренировка ещё
не записана). Оба напоминания открываются той же кнопкой в приложение.

## 6. Логика, которую сервис выполняет за тебя

Не изменилась по сравнению с текстовым ботом — вся арифметика в
[core.py](core.py) и [program.py](program.py):

**Прогрессия веса:** выполнил все подходы и повторы → в следующий раз +2,5 кг
в жимах и тягах, +5 кг в приседе и румынке. Недобрал → тот же вес. Недобрал
второй раз подряд → минус 10% и заход заново.

**Ротация:** фаза 1 чередует A/B по факту записанных тренировок, а не по
календарю. Пропустил неделю — продолжишь с того же места.

**Калории:** база по фазе (2900 / 3100 / 3300) плюс твой сдвиг. Статистика
смотрит на средний вес за 7 дней против предыдущих 7: меньше 0,2 кг/нед две
недели подряд → предложит +200 ккал, больше 0,5 кг/нед → предложит −150.

**Разгрузка:** в фазе 3 каждая 4-я неделя помечается как разгрузочная
(веса 60%, подходов вдвое меньше), прогрессия в эти дни не двигается.

## 7. Настройка под себя

- `program.py` — упражнения, подходы, повторы, шаг прибавки, калории и БЖУ
  по фазам. Меняешь там — и бот, и мини-апп подхватывают сразу.
- `TZ_NAME` — часовой пояс для напоминаний (по умолчанию `Europe/Moscow`).
- `telegram_bot.py` — время напоминаний (`MORNING_HOUR`, `WORKOUT_HOUR`).
- Все данные лежат в файле по пути `DB_PATH` (SQLite). Копируй его — это и
  есть весь прогресс.
- Цвета мини-аппа подстраиваются под тему Telegram (светлая/тёмная)
  автоматически — правится в `frontend/src/main.tsx` / `styles.css`.

## 8. Важное

Я не врач, и сервис не врач: он считает арифметику, а не оценивает твоё
здоровье. Если есть проблемы с ЖКТ, давлением, почками или ты принимаешь
лекарства — покажи план врачу перед стартом, особенно часть про 3300 ккал.
Резкая потеря аппетита, боли, стойкая бессонница на фоне набора — повод
остановиться и разобраться, а не «терпеть по программе».
